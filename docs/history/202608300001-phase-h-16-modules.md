# Refactor: 16 Top-Level Modules Extraction

## Context
Memecah modul `workspace` dan `system` yang sebelumnya bertindak sebagai "God modules", serta menyelaraskan arsitektur ke target 16 modul spesifik (Phase H) sesuai blueprint terbaru.

## Changes
- Mengekstrak `deep_matcher` menjadi modul independen `matching`.
- Mengekstrak `disk_reconcile` menjadi modul independen `reconciliation`.
- Mengekstrak `config` dan `update` menjadi modul independen `settings` dan `updates`.
- Memindahkan `mutation_coordinator` dan `workspace_mutation` menjadi modul terpusat `mutation`.
- Mengubah nama `storage_optimizer` menjadi `duplicates` dan menyatukan `scanner/dedup` ke dalamnya.
- Memperbarui secara global ratusan *import paths* Rust untuk merefleksikan namespace baru.

## Impacted Files
- `src-tauri/src/modules/` (direstrukturisasi masif)
- `src-tauri/src/lib.rs` (dimodifikasi)
- `src-tauri/src/app/runtime/` (dikosongkan dari coordinator)
- `src-tauri/tests/` (dimodifikasi)

## Goal
Batas-batas domain aplikasi kini jauh lebih tegas (mendekati 16 Vertical Slices murni), mengurangi ketergantungan antar-modul secara radikal.

## Impact
- Perubahan namespace besar-besaran (API Tauri Command tidak berubah).
- Tidak ada *breaking changes* pada *logic*. `cargo test` 100% lolos (865 passed).
