# Mod Inbox UX Improvement

## Context
The user found that changing the Mod Inbox location required navigating to the main Settings page, which was inefficient and broke the workflow.

## Changes
- Modified `ModInboxChrome.tsx` header to replace the generic "Settings" button with a "Choose Location" button.
- Updated `ModInboxPage.tsx` to directly invoke the `chooseInboxLocation` folder picker dialog instead of redirecting the workspace to the `games` tab in the settings view.
- Changed the icon from `Settings` to `FolderInput` to better communicate the action.

## Impacted Files
- `src/pages/mod-inbox/ModInboxChrome.tsx` (modified)
- `src/pages/mod-inbox/ModInboxPage.tsx` (modified)

## Goal
To allow users to seamlessly change their Inbox root path inline without losing their current context or navigating away from the page.

## Impact
Better UX, fewer clicks, and zero workspace re-renders needed for configuration changes. No breaking changes.
