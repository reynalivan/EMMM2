# Show the app in the public README

## Context

The README described EMMM without showing its interface. The landing page already had screenshots of the main workflows, but its public URL is not live yet.

Readers can see the library, import review, Collections, and Storage Optimizer alongside their descriptions.

## Impact

Documentation and image assets only. No application behavior changes.
