# Downloads Mod Inbox shortcut

## Context

Downloaded mod archives need a direct route to the Mod Inbox for the next import step.

## Changes

- Added a Mod Inbox shortcut beside refresh in the Downloads toolbar.
- Added EN, ID, and ZH labels and a focused navigation test.

## Impacted Files

- `src/pages/browser/components/DownloadsPage.tsx`
- `src/pages/browser/components/DownloadsPage.test.tsx`
- `src/shared/i18n/locales/en/browser.json`
- `src/shared/i18n/locales/id/browser.json`
- `src/shared/i18n/locales/zh/browser.json`

## Goal

Allow users to move from Downloads to Mod Inbox in one action.
