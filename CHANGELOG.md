# Changelog

## 2.0.0 — 2026-10-17

First public EMMM 2.0 release.

- Manage GIMI, SRMI, ZZMI, WWMI, and EFMI mod libraries across existing folders.
- Import and classify mod folders and ZIP, 7z, and RAR archives with reviewable destination suggestions.
- Browse and edit mod metadata, previews, INI files, favorites, and keybinds; use the optional in-game KeyViewer overlay.
- Save and apply Collections, review changes before applying, and use Safe Mode for classified mods.
- Review duplicate files through Storage Optimizer, with removal routed through the operating system Recycle Bin.
- Install optional signed catalog-pack updates and receive application updates through the signed Tauri updater.
